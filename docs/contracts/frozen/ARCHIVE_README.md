## Important limitations

The current uploaded source set did not contain:
- the actual `D03_V1.2.md`;
- `ARCHITECTURE_SSOT.md`;
- the three exact standalone WP Markdown files.

Therefore this archive deliberately does **not** rename D03 V1.1 as V1.2, does not invent an SSOT, and does not present reconstruction status records as the complete frozen WP contracts.

The three WP documents were marked Frozen in conversation history, but their exact standalone source bytes were not available for byte-level verification in this archive operation.
